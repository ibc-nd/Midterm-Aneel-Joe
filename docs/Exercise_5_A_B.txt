5a) Pairwise alignment is useful for quick, direct comparisons when using a single query sequence to search for similar sequences. It is very fast, works well for identifying closely related homologs, and tools such as the web version of BLAST require little setup. We would use a pairwise search when we have one sequence of interest and want to quickly find sequences that are very similar to it. In contrast, profile-based searching uses a multiple sequence alignment of a gene family to build a profile that represents patterns shared across the entire family. It requires more setup because the reference sequences must first be aligned (using MUSCLE) and then used to build the profile, but it is more sensitive for detecting divergent homologs. We would use a profile-based search when we have several related reference sequences and want to search whole proteomes for members of that gene family, especially when the target sequences may have accumulated more variation.

5b) Building an HMM profile from a multiple sequence alignment is more sensitive than using a single-sequence BLAST query because the HMM captures position-specific patterns across an entire gene family rather than relying on just one reference sequence. The alignment shows which amino acid positions are highly conserved and which positions naturally vary, and the HMM uses those differences to assign probabilities across the sequence. Profile HMMs can also account for insertions and deletions, which helps them recognize related sequences that have changed over evolutionary time. Because the search is based on the shared characteristics of many homologous sequences, an HMM can detect more divergent family members that a single-sequence query might miss.
