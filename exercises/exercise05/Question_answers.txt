5a) Pairwise alignment is good for quick direct searches when comparing a query sequence to a database for single sequences; its sensitivity is attuned to be good for close homologs, it is very quick to process, and it is accessible online and doesn’t require any downloads. On the other hand, profile-based searches are good for screening entire proteomes or gene families; they are best for detecting remote homologs; they are a bit slower than BLAST but still have a fast processing speed; and they require an alignment + build, so unlike BLAST, which just does an alignment, you also need to build a profile in order to set it up to be able to run the search.

5b) Building an HMM profile from an MSA is more sensitive than a single-sequence BLAST query because it incorporates positional variation of amino acids across a gene family and lets it see which positions are always the same versus which ones naturally mutate. BLAST uses uniform alignment rules, but an HMM adjusts alignment based on insertions and deletions and allows gaps in flexible regions. By comparing candidate sequences against the probabilistic rules of the whole gene family, an HMM can catch evolutionary relatives that BLAST would miss.
